A Node program that writes a single one-line, under-280-character 1-star review from a houseplant about its human owner: replaced by a fiddle-leaf fig and exiled next to the router, where its only sunlight is the blinking Wi-Fi light — after surviving three moves and one cat.

## Run it

```sh
node main.ts
```
